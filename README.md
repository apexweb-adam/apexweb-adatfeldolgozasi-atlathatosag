# Apex Web adatfeldolgozási átláthatósági nyilvántartás

Nyilvános, verziózott tájékoztató a HairHungary felhőalapú rendszer szolgáltatóváltási eljárásáról, hordozható adatairól, adatformátumairól, adatszerkezetéről és az adatfeldolgozási infrastruktúra joghatóságairól.

A nyilvántartás az Európai Parlament és a Tanács (EU) 2023/2854 rendelete 25-30. cikkéhez kapcsolódó szerződéses átláthatóságot segíti. Nem adatkezelési tájékoztató, nem adatfeldolgozói megállapodás, nem biztonsági dokumentáció és nem tanúsítvány.

Nyilvános cím: <https://apexweb-adam.github.io/apexweb-adatfeldolgozasi-atlathatosag/>

- `index.html`: ember által olvasható nyilvántartás;
- `register.json`: géppel olvasható szolgáltatásváltási és infrastruktúra-nyilvántartás;
- `schema.json`: a HairHungary adatbázis 0001-0034 migrációs láncából izolált PostgreSQL-környezetben előállított, rekordot nem tartalmazó adatszerkezeti jegyzék;
- `openapi.yaml`: a hitelesített adatkiviteli és szolgáltatóváltási felületek nyilvános műszaki leírása.
